Part 1: Basic HTML forms

Let the browser check

Same contact form, now with built-in HTML5 validation. Try an empty form, a bad email or a short message.

Notes for the defense

  • required blocks an empty field.
  • type="email" checks the format, e.g. a missing @.
  • minlength / maxlength limit text length; maxlength stops typing.
  • pattern regular expression, used for the phone.
  • min / max range for numbers.
  • :user-invalid CSS pseudo-class: red border only after the user touched the field.
