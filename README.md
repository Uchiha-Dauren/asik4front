# Assignment 4: Forms and Validation

A small blog called **Margin Notes** used as the theme for five form tasks. Each task is a separate page, linked from the navbar.

| Page | Task |
| --- | --- |
| `index.html` | Overview |
| `task0-contact.html` | Simple contact form (plain HTML) |
| `task1-html5-validation.html` | HTML5 validation attributes |
| `task2-bootstrap-form.html` | Bootstrap form classes and grid |
| `task3-bootstrap-validation.html` | `is-valid` / `is-invalid` with feedback |
| `task4-registration.html` | Responsive registration form |

## Run locally
Open `index.html` in a browser (internet needed for Bootstrap and fonts from CDN).

## Publish with GitHub Pages
1. Push this folder to a GitHub repository.
2. Settings, Pages, Source: `main` branch, `/ (root)`.
3. Submit the repository link in Moodle.
